# AtmoQuery 南海海温跃变研究

书生国智科探挑战赛 · 地球科学赛道参赛作品代码。

## 研究主题

南海北部海温年代际跃变及其对华南前汛期降水的影响

**核心发现**：南海北部海温在2019年前后发生显著年代际跃变（+0.80°C），伴随海洋热浪频次激增和华南前汛期降水增加（+15.7%）。

## 代码文件

| 文件 | 功能 |
|---|---|
| `01_分析_南海海温与热浪.py` | 南海海温趋势分析、海洋热浪识别、突变检测 |
| `02_分析_华南降水关联.py` | 华南降水提取、海温-降水相关性分析 |
| `03_对比分析_南海vs全球.py` | 南海与其他海域增暖速率对比 |
| `04_交叉验证_OISST_ERSST.py` | 两套独立海温数据的交叉验证 |
| `05_稳健性检验.py` | 稳健性检验（不同阈值、不同方法） |
| `06_空间分布图.py` | 2019跃变幅度的空间分布 |

## 数据来源

- NOAA OISST v2 高分辨率海温数据（0.25°×0.25°，1982-2024）
- NOAA ERSST v5 海温数据（交叉验证用）
- GPCP 全球降水数据（1979-2024）

数据通过脚本自动从 NOAA PSL 数据中心下载，无需手动准备。

## 运行方法

```bash
pip install xarray numpy pandas matplotlib scipy netCDF4 cftime
python 01_分析_南海海温与热浪.py
python 02_分析_华南降水关联.py
python 04_交叉验证_OISST_ERSST.py
python 05_稳健性检验.py
```

分析结果和图表自动保存在当前目录。

## 结论

两套独立数据集均检测到2019年南海海温跃变，结论经过稳健性检验。
